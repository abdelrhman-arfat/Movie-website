# 🎬 Movie Website  

A fully responsive movie website built using **Next, Redux Toolkit, RTK Query, and Tailwind CSS**. It allows users to browse and explore movies with a smooth and modern UI.

## 🚀 Features   
- ⭐ **Add to Favorites & Watchlist** – Save your favorite movies for later.  
- 🔒 **Authentication** – Secure login and logout system.  
- 🎭 **Movie Details Page** – View movie info, cast, and ratings.  
- 🎨 **Modern UI** – Styled with Tailwind CSS for a sleek look.  
- ⚡ **Optimized Performance** – Uses Redux Toolkit for state management and RTK Query for efficient data fetching.  

## 🛠️ Tech Stack  
- **Frontend:** Next , ts , Redux Toolkit, RTK Query, Tailwind CSS  
- **Backend:**  tmDB
